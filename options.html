条件表达式 把多个条件写成一句话；比「关键词 + 评分/日期」表达力强得多

写法：字段 运算符 值，用 &&（且）||（或）!（非）和括号任意组合。
字段：title actress tag maker series director code all rating date； 运算符：~ 包含、=~ 正则、!~ 正则不匹配、= 等于、!= 不等于、> >= < <=（只能用于 rating / date）。
例：rating >= 4 && date >= 2023-01-01 · title =~ /^(SSIS|STARS)-\d+/ && !(tag ~ 巨乳) · (code =~ /^ABC-/ || maker ~ S1) && rating >= 4.5
上面的「模拟卡片」按 字段: 值 每行一条填，用来试表达式命中不命中。 测试用的是页面里同一份引擎（expr.js），这里通过就等于页面上会命中 —— 不是另写一份近似实现。

未分组的规则始终生效。把规则归入分组后，只有该分组开启时规则才生效。在「规则管理」里点 ✎ 编辑即可指定分组。关闭分组 = 整组规则立即失效（页面会自动重新过滤）。

备份与数据

加密备份用 AES-GCM 256，密钥由你设的密码经 PBKDF2-SHA256（25 万次迭代）推导，盐值与初始向量每次都重新随机。 扩展本身不保存密码 —— 忘掉密码就等于文件打不开，请自行记牢。
导入时会自动识别是不是加密文件，是的话会向你要密码。
